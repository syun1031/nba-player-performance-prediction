# 2023–24資料使用說明

本目錄保留NBA官方比賽頁／官方legacy資料的逐場來源快照匯出。比賽清單由歷史每日games頁核對，涵蓋1,230場例行賽、30隊各82場；杯賽冠軍與季後賽不在清單內。取得時間不是當時發布時間。

原始匯出26,554列，包含578個姓名字串、576個官方球員ID。Boban與Bojan有重音符號兩種寫法，不能把姓名字串數直接當人數。跨季接合依官方ID，故不受姓名差異影響。

其中266列MIN=0：161列來源分鐘顯示0:00，105列有正秒數但四捨五入為0，並有2列PTS>0。0:00列沒有足夠出賽狀態判定是否DNP，不能稱全部已確認出賽。這266列全部依使用者規則排除於上季個人統計；實際用於模型的正MIN資料26,288列、571個球員ID。

推薦後續建模使用 **positive_minute_model_data.csv**：只保留MIN>0，依官方ID統一顯示姓名，SOURCE_PLAYER保留原寫法。它與本輪已訓練模型所用的正MIN統計完全相同，沒有重新訓練。

MIN為官方頁面顯示秒數換算的整數分鐘，秒數60按進位處理並保留原字串；不能假設它與NBA統計表使用更細時間精度後的取整逐列相同。2024–25仍使用原CSV的MIN，沒有改成網頁分鐘。

2023–24來源isNeutral旗標全部False，不能因此推論實際沒有中立場。本季只用來建立得分／分鐘／場數背景，沒有使用此旗標。2024–25模型使用另行核對的當季5場中立旗標。
