## 完賽判定

一般Final以官方數字狀態3及完整box核對。數字狀態1或2只有在以下條件全過時，才建立「歷史完賽」衍生紀錄：

- 官網文字明列Final，至少四節且計時器零秒；實際時間也已超過至少48分鐘的比賽長度。
- 每隊五位先發，球員得分加總等於官方比分。
- 球員分鐘合計符合正常或延長賽總分鐘。逐秒資料容許每位正分鐘球員累積最多1秒的截斷差；官方team.minutes若存在，也必須吻合應有總分鐘。
- 另一份官方daily_lineups資料的同一game ID明列狀態3 Final，且兩隊官方ID與先發球員ID完全一致，先發標記Confirmed及Active。

不符合就保留pending，不根據過了幾天或曾經抓到Final而強行解除。官網欄位互相矛盾的底層原因尚無法確認，因此不稱為已證實的快取問題。
