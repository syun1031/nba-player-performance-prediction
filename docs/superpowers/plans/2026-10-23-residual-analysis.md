# 鎖定候選殘差與球員案例 Implementation Plan

**Goal:** 以二月 3462 筆既有驗證預測，說明鎖定 XGBoost／starter 的誤差分布及可展示案例；不改模型、不調參、不評分測試。

**Architecture:** 核對候選、預測檔及原驗證特徵的樣本與真值，重載模型只作 predict 一致性核對。產生逐筆殘差、得分區間與球員彙整、固定規則案例及 Matplotlib 圖表，另存新輸出。

**Tech Stack:** 既有 .venv、NumPy、Matplotlib、joblib、unittest。

**Spec:** 使用者要求補齊殘差分析與球員案例；沿用 time-validation-tuning 的鎖定候選與日期／賽後陣容限制。

## 固定規則

- 殘差＝實際－預測；正值低估，負值高估。MAE／RMSE 不取整或截斷。
- 二月全部 3462 筆皆分析；不因大誤差、未知隊友或少量球員樣本刪列。
- 實際及預測得分區間分別呈現：<0、0～未滿10、10～未滿20、20～未滿30、30以上。空區間 n=0、指標留空，不填0。
- 比較鎖定模型與五場均值基準；實際得分分組是事後描述，不是預測時可用特徵，也不能單憑它判斷模型偏差原因。
- 球員統計涵蓋所有人；選球員案例時要求二月至少8筆合格驗證，比較改善最多、退步最多、MAE最接近中位數者。8筆只是展示門檻，不取代個人／球隊歷史五場規則。
- 另外列最大正殘差與最大負殘差比賽，未達8筆的球員也可出現在單場極端案例；不強制角色對應不同球員。
- 不以案例推定傷病、分鐘變化、缺席或因果原因；只描述資料可支持的差異。
