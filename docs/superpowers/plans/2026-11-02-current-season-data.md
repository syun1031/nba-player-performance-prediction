# 2026–27 預測資料底稿 Implementation Plan

> **For agentic workers:** 使用 superpowers:executing-plans 逐項執行，沿用既有資料收集與未來預測規則。

**Goal:** 依使用者要求取得2026–27例行賽目前可用的模型原始資料，供後續真正的賽前預測使用。

**Architecture:** 沿用NBA官網日頁與box score來源，另建本季不可覆寫的時間快照。只保留25項特徵需要的數據與身份／時間證據；未開打賽程與已完成結果分開。既有2025–26資料只用於上季表現。

**Tech Stack:** Python標準函式庫、既有page擷取函式、unittest、CSV／JSON。

**Spec:** 使用者本次要求與`docs/week1/lineup_rules_2026_10_21.md`。本次只交付資料與手動更新指令，不建立未來預測介面。

## 範圍與取捨

沿用既有已驗證的NBA頁面擷取方式，避免再建一套來源。不重抓舊球季，不用未取得證據的賽前先發，也不抓模型未使用的投籃、抄截等欄位。實際抓取決策由本次執行者依使用者範圍決定。
