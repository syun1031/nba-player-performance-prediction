# 保留測試與高得分誤差 Implementation Plan

**Goal:** 在不訓練、不選模的前提下，評分2026-03-01～2026-04-12的6979筆合格保留樣本，重點呈現高得分場次。

**Architecture:** 開啟測試標籤前保存協議，凍結主模型及九個既有模型的雜湊、特徵順序與比較角色；只呼叫 predict。以相同樣本評估主模型、五場均值與預先列明的次要比較，另存新結果與測試已使用紀錄。

**Tech Stack:** 現有 .venv、NumPy、joblib、Matplotlib、unittest。

**Spec:** 使用者要求最終測試並特別檢查高得分；主模型依已完成的時間驗證協議鎖定為XGBoost／starter九項，不依測試排名換模型。

## 預先固定的比較

- 主比較：鎖定XGBoost／starter與最近五場平均得分基準。
- 次要比較：time_validation_tuning/models/的九個既有模型（線性迴歸／決策樹／XGBoost，各basic／starter／teammates），均不重訓、不重建編碼器。即使次要模型測試分數較好，也不據此重選候選。
- 個人歷史特徵仍只用目標日期之前的比賽；測試期較早比賽可進入後續近期統計，不能更新模型或前處理。
- 主要指標MAE，另列RMSE、平均殘差、誤差5／10分內比例。殘差＝實際－預測，正值代表低估。
- 高得分主分析：實際20分以上與30分以上，兩者重疊，不相加；另列互斥的0～未滿10、10～未滿20、20～未滿30、30以上。
- 全部6979筆皆保留；區間以真值作事後描述，不當作賽前可辨識特徵或因果原因。另列按預測得分分組，避免只依真值分組判斷校準。
- 主模型與基準在整體／20+／30+做同日成對比較，以日期群組重抽2000次、seed42列探索性95%區間，不因結果更改區間或模型。
- 球員案例沿用二月固定選出的三名球員，不依測試成績挑成功球員；另列高得分最大的20筆絕對誤差，清楚標為事後極端診斷。
- 只評估既有日期隔離的假設性回測，歷史先發來自賽後快照。最終測試不等於真實賽前資訊重建。
