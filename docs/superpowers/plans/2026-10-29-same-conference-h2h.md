# 同區先前對陣得分特徵 Implementation Plan

**Goal:** 新增使用者指定的同區對陣記憶，以球員本季先前對同一對手的得分幫助預測，並驗證增益。

**Architecture:** 獨立 `scripts/same_conference_h2h.py` 共用原完整資格入口，原模組不改。球隊東西區對照另存固定球季JSON並附官方來源。另做固定比較與唯讀驗證，輸出 `outputs/week2/same_conference_h2h_v6/`。

**Tech Stack:** 現有Python、NumPy、XGBoost、joblib、Matplotlib、unittest，不新增套件。

## 特徵與缺失規則

- `same_conference`：以本場實際所屬球隊與對手判斷同一conference（不是同division），East／West各15隊。
- `same_conf_h2h_count`：目標比賽同區時，本季此球員此前對同一對手的正分鐘出賽次數；不同區固定0。
- `same_conf_h2h_pts_last_1`：上述紀錄最近一場得分，無紀錄或不同區為缺失。
- `same_conf_h2h_pts_mean`：上述所有已知本季紀錄平均得分，不設三或四場上限；無紀錄或不同區為缺失。

只取同球員、同球季、嚴格前日、MIN>0；正分鐘零分保留。轉隊延續個人對同一對手的記憶，目標比賽是否同區則用目標隊。歷史所在隊是否同區不再過濾，避免無意重置個人轉隊紀錄。跨季重置；未核對球季／未知球隊拒絕，不自行推定分區。

沒有對陣不是0分：兩個得分欄保留缺失（CSV空值→XGBoost原生NaN），以同區旗標和次數區別「跨區」與「同區尚無紀錄」。已有紀錄的壞數值不得假裝無紀錄，不跳過近期壞列；原個人／球隊／對手五場與名單、時間規則不變，沒有對陣紀錄不額外排除樣本。

固定分區來源 docs/week1/conferences_2025_26.json，NBA官方About與2025–26 standings核對；2026-10-29是核對日期，不是歷史發布時間。特徵按實際比賽，不把常見賽程場數當成必然規則。
