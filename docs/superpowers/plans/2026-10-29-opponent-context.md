# 對手失分與得分環境研究 Implementation Plan

**Goal:** 完成第三項優化，以嚴格前日的對手近五場資訊，檢查個人得分預測是否改善。

**Architecture:** 新增 `scripts/opponent_context.py`、`scripts/experiment_opponent_context.py` 與獨立唯讀驗證腳本，另存 `outputs/week2/opponent_context_v4/`。同一組樣本重訓九項、十四項、十六項直接得分模型，原線上九項不變。

**Tech Stack:** 現有Python、XGBoost、NumPy、joblib、Matplotlib、unittest，不安裝套件、不爬新來源。

## 研究決定與限制

第三項原建議為補對手與節奏背景。現有CSV缺FGA／FTA／OREB／TOV，MIN為整數也不足以重建延長賽時間，不能宣稱計算正式Pace或每百回合防守效率。本次先做能被現有資料支持的兩項：

- `opp_points_allowed_mean_5`：對手目標日前最近五場的對方總得分平均（失分代理，非正式防守效率）。
- `opp_combined_points_mean_5`：同五場雙方總得分平均（得分環境，不能稱Pace）。

原始球員紀錄按日期＋兩隊集合聚合成唯一一場，各隊球員得分相加。主客顛倒的中立場仍按兩隊集合配對；不能合併不同日期或把兩個隊伍視角算兩場。零分鐘且零分不加個人樣本，但隊伍總分不丟正分鐘零分；完整原始球員而非已過五場門檻的子集用於總分。聚合時先排除二月底以後日期，再讀當場結果。用原roster的姓名對照核對所有正分鐘球員均在名單，且沒有遺失名單出賽者。

兩項只取同球季、嚴格前日、最近五場，不含目標比賽。對手不足五場不產生特徵；既有個人與自己球隊五場規則保留，完整單筆入口共用陣容／時間規則。
