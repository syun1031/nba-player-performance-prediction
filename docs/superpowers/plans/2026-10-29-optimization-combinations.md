# 三項優化兩兩與全部組合比較 Implementation Plan

**Goal:** 依使用者指定比較1＋2、1＋3、2＋3、1＋2＋3四種情況，找出開發期表現較好的組合。

**Architecture:** 新增 `scripts/combination_models.py` 與研究執行／唯讀驗證腳本。原 TwoStageModel 不改，以子類別明確指定每一組特徵，保留舊研究的程式與輸出雜湊。共用v4的共同樣本與窗口，另存 `outputs/week2/optimization_combinations_v5/`，不替換線上模型。

**Tech Stack:** 現有Python、XGBoost、NumPy、joblib、Matplotlib、unittest，不新增套件。
