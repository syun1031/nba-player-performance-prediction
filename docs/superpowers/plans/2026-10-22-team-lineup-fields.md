# 球隊五場門檻與本場先發 Implementation Plan

**Goal:** 在既有基礎特徵之外新增球隊五場資格、自己是否先發與先發隊友名單，另存資料，不改舊版結果。

**Architecture:** 從完整球隊陣容資料建立同隊同季已完成比賽索引；僅計目標日期以前場次。共用單筆函式接受本場五人名單，歷史模式明示賽後來源；未來模式必須有賽前名單及可核對的時間。

**Tech Stack:** Python 標準函式庫及 unittest。

**Spec:** docs/week1/lineup_rules_2026_10_21.md；不實作尚未定義的先發缺席比較名單。

## 執行決定

歷史名單可以產生欄位，但 live_prediction_ready 必須為 False。未來輸入須標記 pregame_confirmed，且取得時間不晚於預測時間、預測時間早於預定開賽；否則回傳原因，不猜測先發。

球隊不足五場與個人不足五場分別保留原因；新資料沒有隊友缺席比較基準，不新增該特徵，也不刪除替補上場者。
