## 特徵與規則

| 新欄位 | 定義 |
| --- | --- |
| pts_last_1 | 最近一場正分鐘出賽的得分 |
| min_mean_3 | 最近三場正分鐘平均分鐘 |
| min_change_last_vs_5 | 最近一場分鐘減近五場平均分鐘 |
| pts_std_5 | 最近五場得分的母體標準差，ddof=0 |
| min_std_5 | 最近五場分鐘的母體標準差，ddof=0 |

仍需個人及球隊至少五場；同球員轉隊延續個人歷史，跨季重置。排除同日、未來、零分鐘；正分鐘零分保留。必要歷史值缺失不補、不跳過壞列改拿更早資料。單筆未來入口也套用相同規則及原名單／時間／球隊門檻。

- 報告MAE／RMSE、20+／30+與各輪差異；日期群組重抽2000次、seed42，三輪合併時輪內分層抽日期。不得因初步結果追加特徵／參數。
